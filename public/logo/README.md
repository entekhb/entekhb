# 🎨 پوشه اختصاصی تصویر لوگو (Logo Asset Folder)

این پوشه برای قرار دادن تصویر اصلی لوگوی وب‌سایت ایجاد شده است.

## 📌 نحوه استفاده بعد از دانلود سورس پروژه:

1. فایل تصویر لوگوی واقعی خود را کپی کنید.
2. آن را در همین پوشه (`public/logo/`) با یکی از نام‌های زیر ذخیره کنید:
   - **`logo.png`** (پیشنهادی - با پس‌زمینه شفاف یا مربع)
   - **`logo.svg`** (در صورت داشتن نسخه وکتور)
   - **`logo.jpg`** (یا `logo.webp`)

3. **تمام!** نیازی به دستکاری هیچ کدی در پروژه نیست. با راه‌اندازی یا بیلد پروژه، لوگوی شما به طور خودکار در سراسر سایت (نوار ناوبری، هیرو، مودال، فوتر و فاوآیکون) جایگزین خواهد شد.

---

## 📁 ساختار این پوشه:
- `public/logo/logo.png` : فایل اصلی تصویر لوگو که در سایت نمایش داده می‌شود.
- `public/logo/logo.svg` : نسخه وکتور پشتیبان (اختیاری)
- `public/logo/README.md` : این راهنما
- `public/logo/راهنمای_قرار_دادن_لوگو.txt` : راهنمای متنی سریع فارسی
